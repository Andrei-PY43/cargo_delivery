Cargo Delivery

Веб-приложение для организации заказа и доставки грузов.

О проекте

Проект разработан в рамках дипломной работы.

Система предназначена для автоматизации процесса оформления заказа на перевозку груза, обработки заказа администратором и работы водителей с доступными заказами.

Основные роли пользователей:

Клиент — создаёт заказ на перевозку груза.
Водитель — просматривает доступные заказы и может принять заказ на выполнение.
Администратор — управляет пользователями, заказами и процессом доставки.
